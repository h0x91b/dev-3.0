# Decision records — where the old numbered names went

Records used to be `decisions/NNN-slug.md`. They are now `decisions/YYYY/MM/DD/slug.md`,
dated by the day the record was first committed. The number is gone: it never was an
identity — 98 numbers were shared by two to seven records each — while all
369 slugs have always been unique.

**This table is the bridge for old citations.** A merged PR body, a GitHub issue, a code
comment or an agent's memory that still says `decisions/205-sensitive-projects-in-streamer-mode.md`
resolves here in one grep. A bare "decision 205" resolves to every row whose old name starts
with `205-` — the same ambiguity that citation always had, no worse.

Why this shape at all, and why the old records were renamed despite the cost:
[`2026/08/06/decision-records-dated-not-numbered.md`](2026/08/06/decision-records-dated-not-numbered.md).

**Writing a new record?** `decisions/YYYY/MM/DD/your-slug.md`, never a number. Do not add rows
to this table — it is a frozen map of what was renamed once, not a registry.
