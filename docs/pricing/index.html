Pricing

dev-3.0 is free

Free and open source under the Apache 2.0 license. There is one edition, no paid tier, no per-seat license and no account to create.

What you do pay for: your agents

dev-3.0 runs the coding agents you already use — Claude Code, Codex, Gemini CLI and the rest — under your own account with each provider. Their subscriptions or API usage are billed by that provider, on that provider's terms. dev-3.0 does not resell, mark up or proxy them.

What you get for free

  • The desktop app for macOS and Windows, and the headless dev3 server for Linux and macOS.
  • Every feature: the board, worktrees, terminals, diff review, remote access from a browser or phone, the CLI.
  • The source code, to read, change and build yourself.

Release builds send anonymous usage analytics, which one switch turns off: Settings → System → Telemetry, or DEV3_TELEMETRY=off. What is collected is listed in the README.
