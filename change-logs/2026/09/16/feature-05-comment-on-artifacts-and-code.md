Short: Comment on artifacts, not just diffs

HTML artifacts get a comment mode: click any element of a report, comment beside it, and send it to the agent the same way as a diff comment. Review comments now live on the task instead of the browser, so the same list shows on the desktop, on a phone, and to the agent through `dev3 review list`, which can close a comment with `dev3 review resolve <id> --reply "…"` — the reply appears under the comment and its pin turns green.
