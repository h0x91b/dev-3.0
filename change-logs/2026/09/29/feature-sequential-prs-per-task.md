Short: Follow-up PRs in the same task

A task can now open a follow-up pull request after its first one merged or closed: Create PR comes back beside the finished PR's badge, Merge no longer points at the dead PR, commits made after a merge no longer trigger the "is the task complete?" prompt, and the replaced PRs stay listed under "Earlier pull requests" in the PR popover, in the archived task view, in search and in `dev3 task show`.
