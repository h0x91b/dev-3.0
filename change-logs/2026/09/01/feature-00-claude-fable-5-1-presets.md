Short: Claude Fable 5.1 presets

Claude Fable 5.1 joins the built-in Claude presets on its 1M-context alias (`claude-fable-5-1[1m]`) with Medium/High/X-High effort tiers for Auto and Bypass plus Default, Plan and Accept Edits, listed above Fable 5 in every mode group. The Fable 5, Opus 5, Opus 4.8, Sonnet 5 and Opus 4.7 presets and the default configuration are unchanged; the usage-cost table prices Fable 5.1 and Opus 4.8 cache reads at their published $0.25/MTok instead of the generic 10%-of-input default. The `/debug-ui` skill now routes the scoped QA board through `dev3 dev-server` via `DEV3_QA_SCOPE` in `.dev3/config.local.json` instead of a hand-run `bun run dev --qa`.
