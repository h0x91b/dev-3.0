Short: Space becomes a breadcrumb level

A project can belong to several spaces, and the header used to forget which one you came through the moment you opened a task — the Active Tasks sidebar then pooled every space the project belongs to instead of the one on screen. The space is now its own crumb between the app name and the project (dev-3.0 / AI / Nanochat), a plain link back to that space's board, and it survives Back/Forward and a full-page task; Active Tasks holds exactly that space's projects.
