Short: Artifacts open in the side panel again

An HTML artifact opens in the resizable panel to the right of the task terminal again, so a report can be read beside a live agent. The centred popup is still there as an opt-in — Settings → Tasks & Board → "Open artifacts in a popup" — for anyone whose UI freezes with the panel; switching the setting while an artifact is open moves it without losing the page, version or an unsent form. On a phone the popup is still used, because a side panel that narrow is unusable.
