Short: Open a PR from the CLI

New `dev3 pr create --title "..." [--description "..."] [--base <branch>] [--draft] [--auto-merge[=squash|merge|rebase]]` and `dev3 pr auto-merge [<number|url>] [--strategy <m>] [--off]`: the first pushes the branch checked out in the worktree, opens the pull request through `gh`, targets the base branch the task was created from and appends the origin-task footer unless the user turned it off; the second sets or clears auto-merge on a pull request that already exists. An unauthenticated or missing `gh` is refused with the new exit code 23 before anything is pushed. Every prompt that used to spell out the raw `gh` recipe — the Create PR handoff, the agent protocol body, `ask-dev3` — now points at these commands instead. A switch that was given a value (`--off 1722`, `--draft yes`) is refused rather than guessed — a bare switch swallows the next token, which made `--off 1722` read as "not off" and enable auto-merge instead of clearing it.
