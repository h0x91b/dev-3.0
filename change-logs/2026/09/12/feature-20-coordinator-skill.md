Short: Promote this task to coordinator mid-chat

A new bundled `/dev3-coordinator` skill turns the task an agent is already working in into a board coordinator without restarting it — the conversation, the work already done, the branch, title, labels and priority all stay as they are. It runs `dev3 task update --type coordinator --print-role`, a new flag that prints the effective coordinator brief to the caller instead of typing it back into the caller's own pane, so the skill needs no copy of the brief and cannot drift from the one new coordinator tasks start with. The coordinator brief itself now defaults to creating a task and asking to launch it in the same step instead of asking twice, and treats a declined launch as the user parking the task rather than something to retry or question.
