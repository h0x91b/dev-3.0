Short: Open task works on finished traffic nodes

"Open task" in Agent traffic used to send a completed or cancelled task to the Active Tasks pane, which has nothing to show for a task with no terminal, so the click looked like it did nothing. Those now land on the task's own project Kanban with the same detail view its card opens on click — including a task buried behind a column's "show more", and a task in a project other than the board you were on. Active tasks open their workspace exactly as before, and a task that no longer exists says so instead of opening an empty board.
