Every project-scoped CLI command now resolves its default project from where the shell is: the task worktree as before, and additionally the registered project whose checkout contains the cwd, so `dev3 label list` or `dev3 tasks list` work from a plain clone instead of answering "could not detect project". `dev3 peek` and `dev3 pane` no longer search every board when no `--project` was given — a bare `seq:N` means this project's task, because every board counts seq from 1; `--project <id>` is the cross-project escape hatch, and a ref this board lacks now names the boards that do carry it instead of silently resolving a stranger's task.
