Short: Simplify View + per-control hiding

Add per-control hiding: right-click any of a set of advanced controls to hide it (touch/remote get an inline Hide icon instead), and restore it later from a single restore control — one in the task inspector's chrome (grouped by bar, with a "Show all"), one folded into the header's kebab for its three hideable controls. A new "Simplify View" toggle (Settings → System → Advanced Experience) is a preset built on the same mechanism: turning it on hides agent traffic, stats, automations, spawning extra variants or agents, bug hunters, hibernate, scheduled messages, tmux pane controls, the scripts runner, the no-dev-script setup prompt, the keyboard-shortcut editor, and custom-column/label creation, leaving the core create-task → Kanban → terminal → git loop in view. Off by default; hiding a control never deletes what it already created, and nothing hidden stops running underneath.
