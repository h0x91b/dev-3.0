Short: Agents exit cleanly when a task ends

Completing, cancelling, hibernating or deleting a task now asks the agent to quit on its own terms before the terminal is torn down: dev3 types the CLI's quit command (Ctrl-C, then `/exit` or `/quit`, then Enter) into every pane where it can see that agent actually running, and waits up to 30 seconds for the pane to go quiet, so Claude Code's SessionEnd hooks — and any other harness's exit-time work — finish before the worktree process reaper and the worktree removal, which used to kill a hook mid-flight. A hook that outlives the agent still gets its time; a hook that hangs only costs that bound. Nothing is typed at a pane running something that is not the agent, nor at a CLI that has not been proved to be at its prompt — a trust dialog or first-run wizard would read the Enter as an answer — and on a platform with no readable process table (Windows) the step logs that it is skipping instead of guessing.
