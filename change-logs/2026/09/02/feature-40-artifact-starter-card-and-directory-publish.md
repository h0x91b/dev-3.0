Short: Publish an artifact directory in one line

`dev3 show-artifact ./dev3-artifact-report --title "…"` now publishes a whole report directory — `index.html` plus every CSS, JS and image under it — instead of a six-line command naming each asset. The starter's `AUTHORING.md` shrank to a one-screen card with a class cheat sheet, the depth moved to a new `REFERENCE.md` read by section, and a `<table data-sortable>` is sorted by the shell so a static report needs no JavaScript.
