Short: Right-click any task

Right-clicking a task — in the Active Tasks sidebar or on a Kanban card — now opens a full task menu: labels, priority, move to status or project, rename, copy deep link / branch / worktree path, Open in…, watch, hide from sidebar, hibernate and delete. On touch a long press opens the same menu as a bottom sheet, and Shift+F10 opens it from the keyboard.
