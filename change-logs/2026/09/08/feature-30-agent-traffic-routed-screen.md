Short: Agent traffic is a real screen now

Agent traffic is a routed screen instead of a fullscreen popup: it opens under the normal app header with working Back/Forward and a breadcrumb, so ⌘1–9, the palette and the go-to chords no longer navigate behind it. Entering it picks the last hour and replays it once on its own — a refresh, a re-render or a newly arrived message never restarts the replay, an empty hour stays parked, and reduced motion parks the cursor at the start instead of playing. ⇧⌘M and Escape leave the screen the way they closed the popup, and the View menu, palette and header pill all still get you there. The screen also carries the event-kind filter the shared replay timeline needs; it stays hidden until the timeline actually carries more than one kind of event.
