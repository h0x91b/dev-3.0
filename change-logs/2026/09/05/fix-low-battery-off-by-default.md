Short: Low-battery format is now opt-in

The low-battery answer format no longer installs itself: a fresh install ships nothing, selects no Claude Code output style, and adds no line to ~/.agents/AGENTS.md until you turn it on in Settings → Agents → Low-battery answer format. An install from the earlier default-on release keeps its files until you flip that switch on and off again, which is a real uninstall of what dev3 wrote; `dev3 doctor` names those leftovers.
