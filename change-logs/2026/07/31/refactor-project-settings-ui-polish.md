Short: Calmer Project Settings screen

Project Settings got a craft pass: the 12-swatch colour palette on every label and custom column collapsed into a popover behind the colour dot, reorder arrows now appear on row hover (still always visible on touch), and the long config tabs are grouped into named sections with dividers instead of one flat wall of fields. Deleting a label or a custom column now asks first and says how many tasks it affects, switches and tabs got real focus rings and ARIA roles, and an over-limit column instruction no longer silently fails to save.
