Short: Agents can ask to start tasks

An agent working in one task can now ask you to start another one: `dev3 task move --task seq:<N> --status in-progress` on a task that is not its own opens an approval dialog with the usual Provider/Model/Mode picker, so you choose which agent runs it and can decline outright, while `dev3 task create --scratch --run` does the same for a fresh throwaway peer that starts with no prompt. Approval launches the task with exactly the agent you picked, tells it which task asked for it so the two can talk over `dev3 message`, and hands the requesting agent the new task's number; declining launches nothing and discards an unwanted scratch placeholder. This also closes the hole where an agent could already activate any To Do task silently with the stored default agent and no dialog at all.
