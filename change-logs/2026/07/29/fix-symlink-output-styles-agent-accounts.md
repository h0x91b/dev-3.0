Short: Agent accounts share all Claude config

Per-agent Claude config dirs now symlink every entry of `~/.claude` except the five that make an account an account (login, identity, usage, org policy, per-user flags), plus anything credential-shaped by name — so `output-styles`, `workflows`, `routines`, `hooks` and imported `*.md` memory files stop silently going missing. Existing accounts pick up whatever is absent on the next launch, and a configured `outputStyle` that matches no registered style is now logged with the names that do exist: Claude Code registers a style under its frontmatter `name` instead of its filename, so `low-battery.md` declaring `name: Low Battery` is only reachable as "Low Battery".
