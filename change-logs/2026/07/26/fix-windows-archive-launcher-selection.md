The Windows packaged-app launch proof now finds the real desktop launcher at `bin/launcher.exe` instead of scanning the bundle root, which found nothing and kept the `windows-app-archive` job permanently red. Auxiliary executables — the bundled `dev3.exe` CLI, the native terminal host image, setup carriers and the electrobun runtime binaries — are rejected with an explicit reason, missing and ambiguous layouts fail with the full considered inventory, and the executable inventory is uploaded as proof even when the check fails.
