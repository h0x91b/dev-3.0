Add a standalone, production-unused manifest generator and validator for staged native terminal host artifacts under scripts/native-terminal-host-manifest/. It emits deterministic JSON (schema version, host/protocol/Bun versions, OS, arch, entrypoint, per-file sizes and SHA-256 checksums) and re-validates an artifact directory, rejecting missing, partial, path-traversal, duplicate, incompatible-schema, and checksum-mismatch inputs with compact typed errors. Groundwork for the tmux-removal roadmap; packaging, signing, and update flows are untouched.
