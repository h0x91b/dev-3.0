Decision records moved from a sequential `decisions/NNN-slug.md` to dated directories, `decisions/YYYY/MM/DD/slug.md`, the same shape as change-logs and for the same reason: parallel agents branching off the same main all read the same "next" number and all take it, so 98 numbers on main were already shared by two to seven records each. All 369 existing records were moved in one pass, dated by the day they were first committed, and `decisions/README.md` maps every old name to its new path so existing citations still resolve. A test enforces the layout, since the prose rule is what failed the first time.
