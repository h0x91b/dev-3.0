Added anonymous PostHog product analytics to the renderer, covering project creation, task create/edit/move/spawn, and branch actions such as rebase, commit, push, PR creation and merge, plus unhandled error and promise-rejection capture. No user identification and no PII is sent; without a build-time `VITE_POSTHOG_KEY`/`VITE_POSTHOG_HOST` the client falls back to a no-op so nothing is captured. The release workflow now passes both values into every "Build release" step so packaged builds get a live client, and Vite's `envDir` points at the repository root so the `.env` documented in `.env.example` is actually read. `posthog-js` is pinned to an exact `1.407.2` because release-age policies on mirroring registries reject tarballs published hours earlier, which made the previously locked version impossible to install.
