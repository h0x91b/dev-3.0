The required status checks on main now wait for the packaged Windows jobs instead of merging ahead of them: the Windows packaging workflow became a reusable workflow called from build.yml, and its 45-entry path filter moved into code as a single source of truth so out-of-scope pull requests still skip it. A pull request can no longer merge while the Windows proof is still pending, and a Windows job that did not run says so out loud rather than passing in silence.
