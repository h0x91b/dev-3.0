Short: Lifecycle rail in the sidebar

The Active Tasks sidebar row now carries the same lifecycle rail as the Kanban card: a status ring that opens the Move-to menu, the attention bell, and one-click complete, with the upright status word appearing only on rows tall enough to hold it whole. The row leads with the task title and demotes the agent config to a muted line at the bottom, so what identifies a task outranks what is identical on almost every task.
