Short: Toasts say where they came from

Every toast now carries a source line saying where it came from: the task number, project and title for task work, the project name for project-level messages, or the app area (Settings, Update, Dashboard, Terminal, Menu) for everything else — and clicking a task or project toast takes you there. A call site only names its origin with one token; the toast host composes the rest, so new toasts are correct by default.
