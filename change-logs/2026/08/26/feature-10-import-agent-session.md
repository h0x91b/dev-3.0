Short: Import an existing agent session

The New Task modal now has two modes: Describe writes a prompt as before, Import picks up an agent session you already ran in this project outside dev3. Choosing one fills the title, description and branch from its own transcript — all editable — and saving relaunches that conversation with --resume on a branch forked from the one the session was on. Claude and Codex sessions are supported, and only sessions from the project that owns their directory are offered.
