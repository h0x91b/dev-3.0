Short: Task notifications reach your phone

Task notifications can now leave the machine, so a blocked agent reaches you when dev-3.0 is closed and no browser tab is open: a command or webhook you configure in `~/.dev3.0/notifications.json` receives each one as JSON on stdin, and any browser served over HTTPS — including an iPhone with dev-3.0 added to the Home Screen — can register for Web Push, with the payload encrypted end to end so the push service relays it without being able to read it. dev-3.0 runs no server for either and never picks a destination: an install with no config and no registered device sends nothing anywhere, and the VAPID keypair is generated locally. The first time a browser could accept push it is offered once as a dismissible toast that runs the whole enrolment in a tap; ignore it and it never asks again.
