Short: Task notifications reach your phone

Task notifications can now leave the machine two ways, so a blocked agent reaches you when dev-3.0 is closed and no browser tab is open. A command or webhook you configure in `~/.dev3.0/notifications.json` receives every notification as JSON on stdin, which works in any mode including a plain-HTTP LAN address. And any browser served over HTTPS — including an iPhone with dev-3.0 added to the Home Screen — can register for Web Push under Settings, with the payload encrypted end to end so the push service relays it without being able to read it. dev-3.0 runs no server for either: it never picks a destination, an install with no config and no registered device sends nothing anywhere, and the VAPID keypair is generated locally and never leaves. The first time a browser could accept push, dev-3.0 offers it once as a dismissible toast — tapping it runs the whole enrolment — because a control buried in Settings is a control nobody finds; ignore it and it never asks again.
