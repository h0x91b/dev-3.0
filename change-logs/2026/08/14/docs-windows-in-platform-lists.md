Short: Windows listed everywhere platforms are

Every place that tells a human which platforms dev-3.0 runs on now lists Windows — the landing page (platform badge, install card, download caption, JSON-LD, social card), the README badge and platform table, the install guide, `llms.txt`, the agent install brief, AGENTS.md and concept.md — each carrying the same honest note that Windows support is brand new and may still be rough. Where the reader is about to download, the docs now say where the build actually lives: the Windows x64 zip ships in the canary channel only (the stable release page has no Windows file yet) and is unsigned, so the first launch goes through a SmartScreen warning. This also corrects the install guide, which pointed at a `stable-win-x64` download link that 404s today.
