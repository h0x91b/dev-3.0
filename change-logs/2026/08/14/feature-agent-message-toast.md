Short: See when agents message each other

When one task's agent sends `dev3 message` to another task, a violet toast now names both sides — `#7 Coordinator → #42 Receiver` — with a preview of the text, and clicking it opens the receiving task where the message landed. Human-sent messages and sends that reached no live agent stay silent, and the toast is dropped when either side belongs to a sensitive project in streamer mode.
