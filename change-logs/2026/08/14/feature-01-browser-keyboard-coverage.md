Short: Full keyboard in the browser

Keyboard shortcuts now work properly in browser remote mode. Ctrl combos are left to the shell while a terminal has focus, so Ctrl+D sends end-of-file instead of splitting a pane, and the pane keys moved to Ctrl+Shift off macOS as in every terminal emulator. Combos the browser keeps (⌘W, ⌘T, ⌘0, F11) now show their working alternative instead of doing nothing, ⇧⌘Space always opens the Command Palette, and going fullscreen in a Chromium browser hands the whole keyboard back to the app.
