Short: Send one review comment at a time

Every inline comment in the diff review now has its own "Send to agent" button, so a comment can go to the agent the moment it is written instead of waiting for the whole review. A sent comment is marked "Sent" and drops out of the batch payload, so "Copy to Clipboard" and the batch "Send to Agent" only carry comments that have not been sent yet; editing a sent comment makes it deliverable again.
