Short: Rebind any keyboard shortcut

Settings has a new Keyboard category listing every app-level shortcut: click the keys shown on a row and type the combo you want, and if another shortcut already owns it you are told whose before you take it. Each shortcut now has a main combo plus an optional second one, set independently, so an alternative is a thing you add rather than a quirk of the defaults. Filtering matches the keys as well as the name, so `⇧⌘` narrows the list to Shift-Command shortcuts. A few structural ones stay fixed and say why — the `g …` key sequences, the ⌘1–9 project family, the hold-to-cycle task switcher and Esc. The "iTerm2 compatibility" toggle is gone: ⌘D, ⌘⇧D, ⌘W and ⌘T are simply how dev3 works now, and like every other shortcut they can be rebound or unbound one by one. The ⓘ button beside the terminal opens the full ⌘/ shortcuts overlay instead of a partial popover. One behavior change on macOS: the app modifier is now strictly ⌘, so Ctrl combos that used to double as app shortcuts (⌃, ⌃= ⌃`) go to the terminal where they belong.
