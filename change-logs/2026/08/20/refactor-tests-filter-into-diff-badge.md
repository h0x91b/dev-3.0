The with/without-tests toggle is no longer a chip of its own: in both the task summary bar and the diff toolbar it is now a nested icon segment inside the changed-files readout, boxed like the quick-complete segment of the status control, showing a struck-through flask while tests are excluded. Test files are excluded by default. Task labels left the summary bar for a hover card on the breadcrumb title, which also carries the branch name, the task number and how long the task has been around. In the git row the ahead/behind counts went grey so they stop competing with the uncommitted diff, whose +/− now reads green for added and red for removed lines.
