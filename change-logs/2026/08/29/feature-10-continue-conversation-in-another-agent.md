Short: Continue a task in another agent

"+ Agent" can now hand the new agent the conversation that has been running. Tick "Continue this task's conversation" and dev3 writes a retelling of the session — your prompts and the agent's replies verbatim, its actions summarised — beside the task's other files, then points the new agent at it. Start in Claude Code and finish in Codex, or the other way round, in the same worktree. Agents cannot resume each other's sessions, so a switch is a retelling and says so on its first line.
