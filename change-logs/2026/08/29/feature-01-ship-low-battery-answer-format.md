Short: Agents answer in low-battery format

dev3 now ships the low-battery answer rules to every supported agent — a header block that re-establishes what the task is, the decision at the bottom, tables instead of prose — so a task you come back to after two days is readable in seconds. It is on by default and switchable off from Settings → Agents → Low-battery answer format; turning it off removes only what dev3 installed and never touches your own Claude Code output style.
