Short: Switch default account from usage panel

The header rate-limit pill's panel now lets you switch the default agent account: it shows the same per-account quota cards for every Claude and Codex account, and each card is a radio row — pick one to make it the default for new launches, exactly as in Settings → Agent Accounts. Hovering the pill keeps the panel read-only; a click pins it, and only a pinned panel lets you choose, so a durable setting is never one stray click away. The switch confirms itself with a toast naming the account it moved to.
