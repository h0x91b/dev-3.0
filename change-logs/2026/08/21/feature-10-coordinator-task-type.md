Short: Coordinator task type

The new-task popup now has a Task type selector — Standard, Coordinator, or PR review — sitting directly under the description instead of the old PR-review toggle hidden inside the branch block. Picking Coordinator drops a built-in brief above your own text: manage other tasks, delegate anything that touches code, and report a self-contained status every time. Both preset prompts are editable app-wide in Settings and per project in Project Settings.
