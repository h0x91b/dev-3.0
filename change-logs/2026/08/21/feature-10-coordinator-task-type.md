Short: Coordinator task type

The new-task popup now has a Task type selector — Standard, Coordinator, or PR review — sitting directly under the description instead of the old PR-review toggle hidden inside the branch block. Picking Coordinator drops a built-in brief above your own text and marks the task as the board's coordinator: its card wears a dashed green border and a Coordinator chip, it sorts above every priority on the board and in the active-tasks sidebar, and it never auto-completes after a merge. Any task can be promoted or demoted later with `dev3 task update --type coordinator|standard`, which also rewrites the role brief in the description and tells the running agent, so the badge never claims a role its agent was not given. Both preset prompts are editable app-wide in Settings and per project in Project Settings.
