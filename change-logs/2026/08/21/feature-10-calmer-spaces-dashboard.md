Short: Calmer dashboard, spaces you can edit

The dashboard drops its cross-project task panel, which was listing the same waiting tasks the project rows already show, and every project row gains an "Open board" footer stating the work it is not showing (including how many tasks sit in To Do). Dragging a project now collapses every project row in that space to a single line for the duration of the drag, so the whole list you are reordering fits on one screen. Every space carries one "…" menu — on its rail row as well as its group header — holding "Edit projects…", Move up / Move down, Rename and Delete: the membership dialog lists every project with the current members ticked, so the same screen both adds and removes, and the old add-only "+" is gone. Spaces finally explain themselves through an (i) and help mode, including what the amber and blue dots count. A space's project rows are now indented under its header with a hairline rule, so the grouping is visible and not merely spaced; the rail rows dropped their amber/blue activity dots (the group headers still say "3 need you" in words, which was the dots' only legend anyway) and a board that cannot be reordered no longer shows a dead grip and two disabled arrows. The rail hides on its own container's width rather than the window's, and below that width the space filter moves into a bottom sheet opened from the search row instead of being silently cleared, and a project's Spaces field in Project Settings wears the app's removable chips instead of a bordered box with an "Edit…" link. A space can now be marked hide-on-camera in its own right, blurring its name in streamer mode wherever it appears rather than only when one of its projects is marked; the rail's "New space" is drawn as a proper bordered button, the overview row is called "Everything" now that it lists spaces too, and on touch a space's "…" is a 44px control at the right edge of its header instead of a hairline glyph mid-row.
