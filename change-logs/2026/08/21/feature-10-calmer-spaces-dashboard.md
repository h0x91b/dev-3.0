Short: Calmer dashboard, spaces you can edit

The dashboard drops its cross-project task panel, which was listing the same waiting tasks the project rows already show, and every project row gains an "Open board" footer stating the work it is not showing (including how many tasks sit in To Do). Dragging a project now collapses every project row in that space to a single line for the duration of the drag, so the whole list you are reordering fits on one screen. Every space carries one "…" menu — on its rail row as well as its group header — holding "Edit projects…", Move up / Move down, Rename and Delete: the membership dialog lists every project with the current members ticked, so the same screen both adds and removes, and the old add-only "+" is gone. Spaces finally explain themselves through an (i) and help mode, including what the amber and blue dots count. Group spacing now says which project rows belong to which space, the rail hides on its own container's width rather than the window's, and a project's Spaces field in Project Settings wears the app's removable chips instead of a bordered box with an "Edit…" link.
