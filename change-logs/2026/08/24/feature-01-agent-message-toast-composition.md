Short: See who wrote to whom at a glance

Messages between agents no longer stack up as identical violet notifications. An agent toast is now a small composition: the task at the centre of the traffic sits in its own box on the left, and every task it talked to gets a box on the right, split into what came in and what went out, with the message text on the wire between them. Every box names its task and opens it on click, repeat messages from one task fold into a single box with a count, and a slow dot runs along each wire in the direction the message travelled.
