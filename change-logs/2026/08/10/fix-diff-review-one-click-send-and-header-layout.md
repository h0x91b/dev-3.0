Short: One-click send in diff review

Throwing a single remark at the agent from the diff cost three clicks — add the comment, send it, delete it — so the comment composer now has a Send now button that ships it immediately and keeps it out of the review. The Review export card shrank to its title line: the count is plain text instead of a boxed number that looked editable, Copy, Send and an icon-only Reset sit in one compact row, and an empty review shows no buttons at all. Comment cards now read "Comment 1/2". The per-file header in the diff no longer squeezes long paths into a one-character-per-line column on medium window widths — the path stays on one line and the Preview/Read controls wrap instead.
