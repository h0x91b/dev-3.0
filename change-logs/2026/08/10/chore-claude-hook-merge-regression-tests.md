Hardened dev3 hook installation against a malformed .claude/settings.local.json: shapes that previously threw (a non-array hooks event, a null root, a broken matcher group) now install cleanly instead of silently launching the agent with no hooks, a UTF-8 byte-order mark no longer wipes the file, and a string or array root no longer injects numeric keys into the user's settings. dev3 also re-asserts the Claude hooks before every prompt it delivers, so a task keeps moving between columns even when Claude Code or an MCP server rewrites that file mid-session.
