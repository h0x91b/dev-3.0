Short: Dashboard accessibility and polish

Reworked the Dashboard after a full interface review: the background-work line now reads "2 agents working" instead of "3 agent is working", removing a project explains that nothing on disk is deleted, truncated project names, paths and task titles are selectable and reachable via tooltip, and the drag handle is no longer a dead tab stop. Contrast was fixed across both themes — solid accent buttons moved to a new `--accent-fill` token so white ink passes AA (5.09:1 instead of 2.98:1), timestamps and counts left the failing muted token, disabled reorder controls became visible again, and user-picked column colours now show as a swatch beside legible text instead of colouring the text itself. The screen also gained a `main` landmark and headings, decorative icon glyphs left the accessibility tree, the help dot got a 24px target, and numbers align on a tabular figure.
