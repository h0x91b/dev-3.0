Short: Choose how tasks are ordered

Settings → Tasks & Board now has a Task sort order preference that governs the order of tasks inside a priority band, on the Kanban board and in the Active Tasks sidebar alike: Oldest first (default) floats the task whose status changed longest ago, Newest first puts the most recently active one on top. It replaces the old Task drop position setting, and manual drag-reordering inside a column is gone — dragging a card still moves it between columns, but its position within one is now derived rather than stored, so the two surfaces can no longer disagree. Tasks in custom columns are now ordered too — they used to render unsorted, which could show a P4 above a P3.
