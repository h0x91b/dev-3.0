The header bar keeps only what you act on: the tmux session list, Quick Shell and the No Sleep toggle moved into the "More" menu, and the memory readout now appears in the bar only when the OS reports pressure (yellow or red) — otherwise it sits in that menu as a row. The menu's icon became horizontal dots in a bordered chip, because the old vertical dots read as one of the header's separators, and the menu now closes on a click anywhere outside it, including over a terminal. In the task bar the Watching bell and the "I decide" toggle lost their text labels (the sentence stays in the tooltip), "I decide" moved to the right of the status chip, and the terminal-shortcuts button now sits with the panel chrome between Worktree Config and Full screen, and the panel expand/collapse chevron moved down to the end of the Runtime bar, right of Images, so it is no longer mistaken for the fullscreen toggle beside it. The git bar dropped the "vs origin/main" compare-ref picker (Project Settings already owns that choice) and the separator between the commit counts and the line counts: ahead/behind and +/- now form one control that opens the diff when clicked. The header and the inspector bars also halved their left/right edge padding, and the "More" menu moved to the far left of the header's utilities cluster so the settings pair keeps the right end. Finally the branch name left the bar for a labelled "Branch" chip: it opens a menu headed by the full name, with Copy branch name / Copy worktree path / Copy checkout command, and the confirmation is a toast that only fires once the clipboard write resolved — the old confirmation lived inside a tooltip nobody was still hovering. The compare-ref choice returned as a "Compare against" section inside that same menu, where it costs no bar width, and it now ticks the row that matches the resolved ref rather than the raw stored value.
