Short: Coordinator task type

The new-task popup now has a Task type selector — Standard, Coordinator, or PR review — sitting directly under the description instead of the old PR-review toggle hidden inside the branch block. Picking Coordinator drops a built-in brief above your own text and marks the task as the board's coordinator: its card wears a dashed green border and a Coordinator chip, it sorts above every priority on the board and in the active-tasks sidebar, and it never auto-completes after a merge. Picking PR review stores the type too, but stays quiet about it: the card just says PR review, with no border and no sort change — it is an ordinary task with a job, not one that outranks the board. Any task can change type later with `dev3 task update --type coordinator|pr-review|standard`, which also rewrites the role brief in the description and tells the running agent, so the badge never claims a role its agent was not given. Both preset prompts are editable app-wide in Settings and per project in Project Settings.
