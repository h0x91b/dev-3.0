Short: First run points at the ? button

A small callout now appears beside the ? button in the header on the dashboard, board, task and project-settings screens, saying that it explains every screen — it goes away for good once you open help mode or close it. A brand-new install also gets a short line in place of the empty Productivity Stats card saying what dev-3.0 does, Spaces and Add project are now explained in help mode, the help icon inside the New Task, Launch and Add Project dialogs is legible instead of a grey dot, empty board columns stop pointing at a New Task button they do not have, the To Do column explains your first task and which save button launches an agent, and tips no longer appear on a board with zero tasks. Tooltips, hover cards and help cards also float properly now instead of looking glued to the surface under them. The Add project dialog now states plainly what dev-3.0 will do to the repository you point it at — each task works on its own branch in its own worktree, your checked-out branch and working copy are untouched, and nothing is pushed until you or an agent you started pushes it. Written after walking the real first run on a genuinely empty home directory.
