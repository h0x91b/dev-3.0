Rebase now runs against the base the branch dropdown promises. In a project with no git remote the button announced the local base branch and then ran `git rebase origin/<base>`, which died with `fatal: invalid upstream` after a failed fetch it had already swallowed. Every git action — rebase, the agent rebase handoff, merge's "not rebased" guard, merge detection, diff stats and bug-hunter scoping — now resolves its ref through the one resolver instead of gluing `origin/` onto a branch name, no fetch is attempted when there is no remote, and a target that does not exist is refused before a pane opens.
