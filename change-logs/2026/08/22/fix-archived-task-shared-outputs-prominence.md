Short: Shared artifacts and images lead a finished task

Reopening a finished task is usually about what the agent shared, so the archived task modal now leads with it: artifacts first as real cards, images as a thumbnail grid instead of a list of filenames, both above the description rather than buried between it and the notes. The modal header carries the same artifact and image count badges a live task has, each section is a real heading a screen reader can jump to, and an artifact row shows its size, version and asset count instead of the `index.html` every artifact is called.
