Short: Help mode now explains the task screen

Press the ? button on a task and help mode finally outlines the task's own two toolbars and the terminal itself, instead of only the app header and the sidebar — the terminal card explains that it is a real tmux session in this task's own worktree, what the bar along the bottom means, and that the agent keeps running when you close the window. The builtin Operations board also gets its own explanation on the dashboard instead of borrowing the one written for git projects.
