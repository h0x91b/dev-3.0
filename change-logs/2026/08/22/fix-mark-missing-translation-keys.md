A translation key that resolves in no locale now renders as ⟦kanban.someKey⟧ instead of the bare key text, so a hole in the translations reads as a hole rather than as copy. Plural fallbacks keep the resolved suffix (⟦ports.count_few⟧) so the missing form is identifiable, and in dev builds the console names every key that was missing, fell back to English, or fell back to the wrong plural form.
