Short: dev-3.0 walks you through task one

The sandbox now comes with a guide instead of an empty board: a small card rings the button you should press, says what it does, and moves along on its own once you press it — from New Task, through the prompt (already filled in with the real rounding bug in the sandbox's prices.js), past the difference between Save and Save & Start, through the Launch dialog, to the agent working in its own terminal and the diff you read before merging. It points at the real controls rather than clicking for you, you can go back or leave at any step, and it never comes back once you have finished or waved it off. If no agent CLI is installed — or one is installed but not logged in — the first-run strip now says so and offers Settings instead of a sandbox whose very first task would have died on a login prompt. Help mode also explains two more things it had been silent about: the Project / Space / Global switcher above the task list, and the "Did you know?" card.
