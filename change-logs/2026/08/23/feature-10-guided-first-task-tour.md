Short: dev-3.0 walks you through task one

The sandbox now comes with a guide instead of an empty board, and it runs the whole loop end to end: a small card rings the button you should press, holds back the rest of the screen, says what that button does, and moves along on its own once the app moves — from New Task, through the prompt (already filled in), past the difference between Save and Save & Start, through the Launch dialog, to the agent working in its own terminal, the dev server serving the sandbox page, the report the agent publishes, the diff, Merge, and the "complete the task?" dialog that closes it. The sandbox itself is now one page with one green button plus a dependency-free server, and the first task is to turn that button blue and show the before and after in a dev3 artifact — a change you can see rather than a diff you have to read. The card's button presses the real control for you, a step that waits on the agent says so instead of pretending it is stuck, and the tour follows the app forward without ever rewinding it: you can go back over an explanation, leave with Escape or "I'll look around myself", and if it loses sight of what it was pointing at it re-finds its place or says so rather than vanishing. It starts again on every visit to an empty sandbox board until you walk it to the end, and after that help mode carries "Walk me through the first task". If no agent CLI is installed — or one is installed but not logged in — the first-run strip says so and offers Settings instead of a sandbox whose very first task would have died on a login prompt. Help mode also explains two more things it had been silent about: the Project / Space / Global switcher above the task list, and the "Did you know?" card.
