Short: Rename a project

Projects can now be renamed: Project Settings → Board → Project name, saved as soon as you press Enter or leave the field. Only the display name changes — the folder on disk, its worktrees, its tasks and every path derived from them stay exactly where they are, and the path is shown under the field to make that obvious. Renaming the built-in Operations board now shows your own name everywhere while it keeps its pinned position and its ⌘0 shortcut. Suggested by Amit Cohen.
