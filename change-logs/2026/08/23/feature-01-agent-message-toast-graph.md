Short: See agent traffic as a graph

Messages between agents no longer stack up as identical violet notifications. One message now shows the sending and the receiving task as two clickable squares, and a burst around one coordinator collapses onto a single card that draws it as a small graph — the hub, its counterparts, and a slow pulse running along each wire in the direction the message travelled. It works the same when three tasks report back to a coordinator as when one coordinator writes to three.
