Short: App no longer sends your IP

Analytics no longer looks up your public IP address from a third-party service, and no longer sends it to Google Analytics; any IP a previous version cached on your machine is erased on the next launch. Your country is now derived from your computer's own timezone instead, with no network call, and no city or region is sent. The rest of the analytics payload was reshaped at the same time: how many projects and tasks you have, and how long ago you installed dev3, are reported only as coarse bands, and no project or task identifier goes into the page address any more. Analytics also reports which build sent an event now, so a canary or source build is labelled as one instead of reading as the stable release on the same version number.
