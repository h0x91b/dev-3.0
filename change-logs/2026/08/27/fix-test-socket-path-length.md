Unix socket fixture paths in the test suites now come from one short, run-scoped socket root instead of the deep isolated temp dir, so they fit the kernel's 104-byte limit by construction. On Node 23 and newer this fixes ten tests in native-pane-owner-forward.test.ts that failed with listen EINVAL; on older Node the same paths were being silently truncated to 103 bytes and bound at the wrong name. An audit test now fails any test file that builds a socket path under a deep temp root.
