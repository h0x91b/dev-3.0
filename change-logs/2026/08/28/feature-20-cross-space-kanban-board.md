Short: One kanban across a whole space

A space can now be the subject of the kanban board itself: a zoom-out button beside the project switcher (⇧⌘U, or pick the space in ⌘K), an "Open space board" button on each space's dashboard header, or a click on a space's heading in the project switcher opens one board showing every member project's tasks on one set of columns, with drag, filters and task creation working exactly as they do on a project's own board. Columns and labels are the union across member projects, merged by name, and a drag only ever changes status in the card's own repository — each card names its project on a line above the task title. A crowded card header no longer squeezes the priority badge into a circle. A space now also has a glyph of its own — three stacked sheets — in the dashboard rail, the dashboard group headers, the project switcher, the mobile filter sheet and the sidebar's scope switcher, which previously showed a plain ring. A project's own board is untouched. The board is addressable as `dev3://space/<id>`, and `dev3 current` now groups a worktree's siblings per space and prints each one's project id.
