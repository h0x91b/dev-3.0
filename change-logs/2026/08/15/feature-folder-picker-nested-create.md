Short: Folder picker creates where you point

The folder picker now creates a new folder inside the folder you highlighted, and says which one on the button and in the name field, instead of always creating in the folder the tree is rooted at. The folder you just created stays selected so Select works right away, the folder you are browsing is now a pickable row of its own, empty folders say they are empty, the tree is keyboard-navigable in single-select mode, and the modal no longer resizes or overlaps its footer when the listing is short.
