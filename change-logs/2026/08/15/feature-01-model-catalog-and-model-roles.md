Short: Run any agent on any provider

Register the providers you pay for in the new **API models** section of Global Settings, ask them what they offer, give the models you want your own names, then bind those names to an agent's own roles in its preset — Claude Code's Opus/Sonnet/Haiku slots, Codex's main/subagent/review models. A pinned proxy sidecar bundled with the app resolves the names, so one Claude Code session can run its main model on OpenAI and its subagents on DeepSeek through OpenRouter. Upstream keys never leave your machine: the agent only ever sees a local proxy key, and a launch is blocked with the offending role named rather than silently falling back to the wrong model. The proxy is infrastructure rather than something you operate: dev3 brings it up with the app on one fixed loopback port and keeps that address across restarts, so running sessions survive a catalog edit. Presets saved in Settings now reach every open board and launch picker immediately, instead of only after the window reloads, and the launcher's first column is labelled **Harness**, because Claude, Codex and Gemini are agent CLIs rather than providers. A hand-built Codex preset now reaches the dev3 CLI as well: dev3 supplies its own permissions preset and profile when the preset itself decides nothing, instead of leaving the agent alive but unable to move the task's status. The Model field captions a routed preset with who serves it (`DS-Flash · OpenRouter`), the providers table says plainly that a subscription is not an API key, and the proxy now ships on every platform dev3 releases rather than Apple Silicon alone. The preset editor's drag handle and up/down arrows are gone: the handle never worked and the arrows permuted an order the grouped list does not show. Codex no longer opens a routed session complaining that it has never heard of the model: dev3 hands it generated metadata for every catalog model, which also restores `apply_patch` and parallel tool calls that its placeholder metadata switched off, and a role left unbound now follows the main model instead of a slug the proxy cannot serve. The launcher no longer waits to be found: with no provider of your own, the Model list shows the open-source models dev3 recommends as locked rows carrying what they cost and what they stand in for (`$4 / 1M instead of Claude Opus 5`), and a **+ Connect a provider…** row is always there regardless. Clicking either opens a one-screen flow — pick OpenRouter, Ollama, Fireworks, Baseten or your own endpoint, paste a key, done — and connecting OpenRouter also names the three recommended models and writes a ready-to-run **Best value** preset into Claude Code and Codex, so the first routed session needs no catalog editing at all. The recommendations go quiet the moment you have any provider of your own. The Model field is wider than its neighbours and its list may outgrow it, so a row reads `GLM 5.2  $4/M vs Opus 5` on one line instead of wrapping; a pencil beside the field opens the preset editor whenever the selected preset is one whose model is a set of roles, so the out-of-the-box choice is a starting point rather than a fixed menu. A custom endpoint can now speak the Anthropic protocol as well as OpenAI's — pick the format when you add it, and the proxy handles the rest. The pencil lands on the exact preset it belongs to, selected and scrolled into view, rather than on the Agents page in general. And when dev3's recommended set moves on in a later release, the preset you are already running says so in one line and shows both sides per role before anything is written — taking the new set or keeping yours are equally final, and the question is asked once. A local endpoint that authenticates nobody (Ollama, LM Studio, your own gateway) is now actually served instead of being refused by the proxy for having no key, a proxy that dies on its own stops reporting itself as running, quitting can no longer orphan a proxy that was still starting, and the credential file is written atomically so a crash mid-save cannot wipe every stored key. A Claude Code preset with only some slots bound now routes the rest at the model it launches with instead of asking the proxy for a Claude model it cannot serve, connecting a second Ollama box or a second hand-entered endpoint no longer collides with the first, the toast after connecting one lands on the model catalog rather than on Appearance, a routed session's cost is priced through the catalog instead of reading as unpriced, and a freshly seeded preset can no longer bind to a model of yours that happens to share a name with a recommended one. A saved API key now shows as a mask with an eye beside it: click to read the key back, and once it is on screen you can replace it or clear the field to remove it entirely — the key is fetched one provider at a time, only when you ask, and a recording blurs it. The unverified OpenRouter-with-Claude-Code warning is gone from the role picker, and a role left empty now says what it actually does — it follows the model the preset launches with. Connecting OpenRouter now seeds two ready-to-run presets instead of one: **Best value** runs Qwen3.8 Max, GLM 5.2 and DeepSeek V4 Flash and starts on GLM 5.2, and **Best value · Smart** puts Kimi K3 on the top slot with GLM 5.2 doing the everyday work and starts on Kimi — so an ordinary turn costs workhorse money and switching to the smarter model is `/model` inside the session, not a relaunch. A preset that names no model of its own no longer opens on the priciest slot it happens to have bound. If you were already seeded, the update prompt offers the new tier as a whole preset and shows every role before writing anything. The third-party rates the launcher quotes were refreshed against what OpenRouter actually charges today. Inside a routed Claude Code session, `/model` now labels each slot with your own name for the model and who serves it (`glm-5.2 · OpenRouter · z-ai/glm-5.2`) instead of a bare wire name against `Custom Opus model`.
