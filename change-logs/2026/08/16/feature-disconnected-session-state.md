Short: Dead sessions no longer look active

A task whose agent session did not survive a force quit or a machine restart now renders like a hibernated one — greyed out, sorted below every live task, and carrying a DISCONNECTED badge on the Kanban card, the Active Tasks sidebar row and the dashboard row. Opening the task still offers the usual Resume Session / Start Fresh recovery, and resuming puts it straight back among the live sessions.
