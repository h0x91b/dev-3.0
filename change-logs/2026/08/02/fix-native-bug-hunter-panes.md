Short: Find bugs works on native tasks

Launching bug hunters on a native task failed with a tmux socket error, because the launch path always split a tmux pane. Hunters now open as real native panes through the shared backend-neutral pane API, stack in an equal column beside the agent's pane, get their prompt through the native pane, and leave keyboard focus with the main agent. A native launch that cannot open every hunter or cannot deliver every prompt is rolled back and reported instead of half-starting, and a pane that refuses to close is named rather than silently counted as gone. tmux tasks are unchanged.
