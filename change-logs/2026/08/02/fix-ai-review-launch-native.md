Short: AI Review starts on native tasks

Moving a task to AI Review did nothing on a task using the native terminal backend: the review agent was launched with a raw tmux split, which cannot work without a tmux session, and the failure bounced the card back to Your Review in complete silence. The review agent now opens a real pane through the backend-neutral seam (no tmux on native, unchanged behaviour on tmux), a repeated activation replaces the running review agent instead of stacking a second one even across an app restart, and a launch that does fail now says so in a localized toast naming the column, where the task went, and what to do about it.
