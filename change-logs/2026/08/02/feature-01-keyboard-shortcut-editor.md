Short: Rebind any keyboard shortcut

Settings has a new Keyboard category where every app-level shortcut can be rebound: click the keys shown on a row, type the new combo, and if another shortcut already owns it you are told whose before you take it. Filtering matches the keys as well as the name, so `⇧⌘` narrows the list to Shift-Command shortcuts. A few structural ones stay fixed and say why — the `g …` key sequences, the ⌘1–9 project family, the hold-to-cycle task switcher and Esc. The tmux keymap preset moved here from Terminal, and the ⌘/ reference overlay now shows your actual combos plus a link to the editor. One behavior change on macOS: the app modifier is now strictly ⌘, so Ctrl combos that used to double as app shortcuts (⌃, ⌃= ⌃`) go to the terminal where they belong.
