Added deterministic automated coverage for native-pane owner routing across dev3 app processes, which was previously proven only by hand. A new three-process E2E drives one real native host: the owning process holds the writer lease and serves the CLI's NDJSON protocol, a second process binds the same pane as an observer and forwards one delivery to the owner, and a reopened third viewer replays the journal to prove the delivery landed exactly once while host and shell identity, the single host process, and the untouched tmux path all hold. The product message E2E now also drives the same routing from outside in, with the request arriving over the non-owning app's own CLI socket as a real message.send rather than an in-process call. A companion unit suite exercises the forwarding transport itself over real sockets, including the loopback endpoint record used on Windows.
