Short: Bigger, highlighted, wrapped file previews

The file preview opened from a terminal path now fills the screen with a small margin instead of a narrow centered box, syntax-highlights source by file type (the same highlighter and colours as the diff viewer, plain text for unknown types), soft-wraps long lines behind a visible, remembered "Wrap lines" toggle, and keeps Markdown table columns at least a word wide instead of splitting words letter by letter — the file and copied content stay unchanged.
