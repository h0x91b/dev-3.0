Short: Rebindable pane focus and tmux prefix

Moving focus between terminal panes now has rebindable shortcuts (⌘⌥+arrows by default, Ctrl+Alt+arrows off macOS) that work on both the tmux and native backends, and a new "Send the tmux prefix" shortcut types ⌃B into a focused tmux terminal, so the prefix can live on a ⌘ key such as ⌘A while ⌘A stays Select All everywhere else.
