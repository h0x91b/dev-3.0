Short: Yazi and dev3 prompt on native

Open in Yazi now works for native-terminal tasks as a toggling, focused pane below the terminal, and finds yazi on Windows too; tmux tasks open it through the same pane path. Native task terminals and their splits now get the dev3 shell prompt, as tmux panes already did.
