Short: Multiple accounts for Oh My Pi

Oh My Pi (omp) now has managed accounts like Claude Code and Codex: Settings → Accounts → Oh My Pi → Add account opens the sign-in window with `omp login` running in a fresh agent directory, you sign in to any provider omp supports (ChatGPT, Copilot, Gemini, …), and each launch can pick which account omp runs on. omp launched from dev3 also defaults to its Nerd Font icon set, since dev3's terminal ships a Nerd Font; a symbol preset you set yourself always wins. The launch picker now lists the models of the providers the selected omp account signed in to, newest first, and launches omp on the one you pick — the newest by default — in Bypass (omp's auto-approve) unless you choose another mode.
