Short: Typing can no longer answer popups

Keystrokes typed while an agent's approval dialog pops up no longer answer it: an unrequested dialog ignores the keyboard until you stop typing for a moment, a key held from before it opened never presses it, Space never presses a dialog button, letters no longer fire app shortcuts behind it, and Y/N no longer answer the close-pane prompt. Enter and Escape remain the answer keys, Escape now closes every confirmation, and mouse clicks work at once.
