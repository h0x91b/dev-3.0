Short: Sign in to new accounts inside dev3

Adding a Claude Code or Codex account in Settings → Agent accounts now opens a sign-in window with the provider's own login running live in a terminal on the dev3 host — no more copying a command into another terminal and pressing Verify. dev3 detects the finished login by itself, works the same from a remote browser (Codex switches to device-code sign-in there), keeps running if you hide the window, and offers retry, cancel and a manual fallback when the CLI is missing. A new Claude account is added only once `claude auth status` confirms that exact login, and dev3 never copies another login's credentials into it.
