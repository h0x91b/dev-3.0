New install guide for running dev3 inside WSL2 with the UI in a Windows browser. It covers full-WSL and hybrid (projects on a Windows drive) topologies, a localhost-only `dev3 remote` with no tunnel, a systemd drop-in with `KillMode=process` so that restarting the service no longer kills running agents, and per-project Claude Code config dirs. The remote-access page now documents the same drop-in for any Linux service install.
