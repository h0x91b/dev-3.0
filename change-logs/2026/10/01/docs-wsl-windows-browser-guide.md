New install guide for running dev3 inside WSL2 with the UI in a Windows browser: full-WSL and hybrid (projects on a Windows drive) topologies, a localhost-only `dev3 remote` with no tunnel, a systemd service, and per-project Claude Code config dirs. The remote-access page now documents an optional `KillMode=process` drop-in for `--no-tunnel` services, so restarting the service no longer kills running agents.
