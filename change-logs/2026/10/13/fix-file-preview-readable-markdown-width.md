Short: Readable Markdown in the file preview

The file preview keeps Markdown prose in a centred reading column (roughly 70–80 characters, widening to about 115 when expanded), while wide tables, code fences, diagrams and images may break out to the full preview width and scroll sideways on their own instead of the whole document. The preview now opens at a size that hugs short files, never shrinks under you while you toggle Wrap lines or Raw/Rendered, and an Expand / Restore size button in its header fills the screen and is remembered for next time.
