Short: Run projects without git worktrees

A project can now switch its git workflow off (Project Settings → Board → Git workflow, or the same switch in the Add Project dialog, which also accepts a folder that is not a git repository), so architecture, discovery and documentation work runs directly in the project folder: no worktree, branch, diff, PR or review columns, and finishing a task keeps every file. Tasks sharing such a folder stay out of each other's way: a Claude edit to a file another live task is editing is refused with that task's name and a ready `dev3 message` command, each task's handoff, Conversation tab and archive show only its own sessions, and dev3's hooks and permissions reach Claude through `--settings` instead of being left in the folder. An Operations task in a folder you chose also no longer has every process in that folder killed when it finishes.
