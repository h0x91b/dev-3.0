Short: Open previewed files in your browser

In browser/remote mode the file preview gains "Open in new tab" and "Download": the file opens in a sandboxed tab of the browser you are using (pages load their own assets but cannot act as you; PDFs download), or downloads to that device, and "Open on Windows" appears when dev3 runs inside WSL and the browser is on the same PC. The image/video viewer, lightbox, attachment cards and the artifact viewer's "Open in browser" now open files the same way in remote mode instead of doing nothing.
