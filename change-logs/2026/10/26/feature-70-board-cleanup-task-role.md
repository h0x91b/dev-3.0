Short: Review board clutter safely

Choose Board cleanup when creating a task to audit open work without waking other agents and receive completion, cancellation, keep or investigate recommendations. Audits default to the current project; explicitly request all projects for a central audit on Operations. Cleanup tasks always complete manually, and the CLI can list a paged open-task inventory with --open --json.
