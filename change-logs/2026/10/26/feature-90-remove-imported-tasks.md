Short: Undo a conversation import

Project Settings → Agent conversations now has "Remove N imported tasks…", which deletes the imported tasks with their worktrees and branches, so a board flooded by an import can start clean again. Any imported task you have already opened, or whose worktree or branch holds uncommitted or unpushed work, is kept and reported, and tasks you created yourself are never touched. The import offer shown right after adding a project now says "Start fresh" instead of "Cancel", so skipping it no longer reads as backing out of adding the project.
