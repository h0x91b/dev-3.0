Short: Review tasks link the PR they review

Review tasks now show a clickable link to the pull request they review on the Kanban card, the Active Tasks sidebar row and the task's git bar ("Reviewing #N"), plus an "Open reviewed PR" row in the mobile git sheet. The PR is stored on the task when it is created and looked up once for existing review tasks; when the task's own PR badge already shows that PR, only one chip appears.
