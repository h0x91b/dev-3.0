Short: One Codex row per signed-in person

The agent limits popover no longer shows a second "Unmanaged login" Codex row when `~/.codex` is signed into the same person and workspace as a managed account: that reading now feeds the managed account's row, and Auto (balanced) is no longer offered for what is really one login. A different person in the same ChatGPT workspace, or a default login whose identity cannot be read, still keeps its own row.
