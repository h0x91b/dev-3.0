Short: Import offer says Skip import, not Cancel

The conversation-import offer shown after adding a project now says the project is already added, explains that importing is optional and can be done later from Project Settings, and labels its dismiss button "Skip import" instead of "Cancel", so declining no longer reads as backing out of adding the project. Opening the import from Project Settings keeps its usual title and Cancel button.
