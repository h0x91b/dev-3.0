Short: Markdown artifacts get a proper reading layout

Markdown reports published with `dev3 show-artifact` now render with a readable text column, clear heading hierarchy, striped tables with a row hover, code blocks and tables that may widen past the text and scroll on their own with soft edge shadows hinting at hidden content, styled task checkboxes, quotes and links with hover and keyboard-focus states, in both themes and on narrow screens. Headings get GitHub-style ids, so `[Section](#section)` links inside a report now jump to their heading. A Markdown or HTML report that merely mentions the `data-dev3-artifact-shell` attribute no longer loses its dark/light theme. Already-published artifacts keep their old look until re-published.
