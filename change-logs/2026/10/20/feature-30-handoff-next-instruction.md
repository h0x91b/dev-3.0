Short: Steer an agent you hand off to

In + Agent, ticking "Continue this task's conversation" now shows an optional "Follow-up prompt" box, empty by default: whatever you type becomes your next message after the retelling (for example "Now review the security of the solution"), so the new agent keeps the earlier context but acts on the new direction instead of just carrying on. Leaving it empty keeps today's behaviour, and the same wording now applies to `dev3 agent spawn --handoff --prompt`.
