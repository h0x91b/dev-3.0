Short: Hand off Cursor Agent conversations

"Add agent to this task" now offers "Continue this task's conversation" when the task's agent is Cursor Agent: dev3 reads Cursor's own transcripts (including the hash-named folders it uses for long worktree paths), so the new agent gets a retelling instead of the option silently missing. Cursor sessions also become searchable with `dev3 conversations search` and appear in the task's conversation view.
