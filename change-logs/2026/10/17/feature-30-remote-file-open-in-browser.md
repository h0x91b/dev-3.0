Short: Open previewed files in your browser

In browser/remote mode the file preview now has "Open in new tab" and "Download": the file opens raw in a new tab of the browser you are using (HTML as a page with its scripts sandboxed, Markdown as plain text for the browser or an extension to render, PDFs and images in the browser's own viewer), or downloads to that device. When dev3 runs inside WSL and the browser is on the same PC, "Open on Windows" opens the file with its Windows default app.
