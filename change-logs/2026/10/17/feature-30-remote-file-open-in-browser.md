Short: Open previewed files in your browser

In browser/remote mode the file preview now has "Open in new tab" and "Download": the file opens raw in a new tab of the browser you are using (pages sandboxed so they cannot act as you, Markdown as plain text for the browser or an extension to render, images and video in the browser's own viewer; PDFs download), or downloads to that device. When dev3 runs inside WSL and the browser is on the same PC, "Open on Windows" opens documents and media with their Windows default app. The image/video viewer, image lightbox and attachment cards now open files in a new tab in remote mode instead of doing nothing (and show an error if opening fails, on the desktop too), and the artifact viewer's "Open in browser" no longer reports an error for a tab that opened and loads the artifact's own assets.
