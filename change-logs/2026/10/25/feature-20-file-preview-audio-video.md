Short: Play audio and video in file previews

Clicking an audio or video file link in a terminal now plays it inside the file preview with native controls (play/pause, seek, time, volume, and fullscreen for video) instead of saying the file is too large. Media streams through Range requests in both the desktop app and remote browser sessions, never autoplays, stops when the preview closes or switches files, and says plainly when the engine cannot play a format, keeping the open-in-another-app fallbacks.
