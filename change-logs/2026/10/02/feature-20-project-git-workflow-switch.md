Short: Run projects without git worktrees

A project can now switch its git workflow off (Project Settings → Board → Git workflow), so architecture, discovery and documentation work runs directly in the project folder: no worktree, branch, diff, PR or review columns, and finishing a task keeps every file. A folder that is not a git repository can be added the same way, and an Operations task in a folder you chose no longer has every process in that folder killed when it finishes.
