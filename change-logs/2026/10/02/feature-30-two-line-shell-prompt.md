Short: Pick your shell prompt style

Shell panes get a new two-line zsh/bash prompt — angled segments with the task number, project, worktree-relative path, git change counters and the last command's duration, then a `└─▶` arrow that turns red on failure, dropping segments in narrow panes instead of wrapping — and Settings → Terminal → Shell prompt lets you pick one of twelve zsh styles from a live preview, write your own from a copy of any of them, or keep the prompt from your own `.zshrc`.
