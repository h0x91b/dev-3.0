Short: See and switch tmux windows in the app

A task terminal with two or more tmux windows now shows them in the app: a slim rail on the left by default, or a row of tabs on top (Settings → Appearance → Terminal windows). The agent's window is marked ✦, named after the task and always listed first, background windows show a dot when they print something or ring the bell, and a window that appears on its own is announced to screen readers. On phones the existing window switcher gains the same names and a one-tap way back to the agent.
