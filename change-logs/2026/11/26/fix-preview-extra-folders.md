Short: Preview opens files in extra folders

A file in a project's extra folders (dev3 extra folders, Claude additional directories, VS Code workspace folders) now opens in the file preview and as a terminal link, instead of showing "File not found". A file outside every folder dev3 can open now says so, instead of claiming it was moved or deleted.
