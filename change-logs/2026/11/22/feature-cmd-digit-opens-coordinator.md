Short: ⌘1–9 from tasks opens coordinators

From Active Tasks or a full-page task, ⌘1–9 (and `G` then 1–9 in remote) now opens that project's most recently used active coordinator task — live first, then sessionless, then hibernated — and still falls back to the project's board when it has none. Board and dashboard behaviour is unchanged, and ⇧⌘1–9 still flips to the board.
