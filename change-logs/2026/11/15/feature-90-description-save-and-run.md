Short: Save & Run when editing a task

The task detail editors drop their separate Save and Cancel buttons on desktop: Run becomes "Save & Run" once the open description has changes, the hints spell out Enter/Esc with the platform's own modifier, and closing the modal saves an open title or description edit; touch devices keep a Cancel button. On a To Do task whose title is still auto-generated, clicking the title now opens the description editor (caret at the end), so text meant for the agent no longer lands in the title; the pencil still sets a custom title.
