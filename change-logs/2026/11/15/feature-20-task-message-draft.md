Short: Draft messages to a task's agent

Write a message to a task's agent outside its terminal: the Send later dialog now autosaves its text as the task's draft, so a peer `dev3 message` can no longer submit a half-written prompt. Keep it as a draft with no send attached, send it now, or pick "When agent stops" to send it automatically the next time the agent finishes its turn; the draft shows as a chip on the card and the open task with Send now, Edit and Discard.
