Short: One-switch prismantis install for Claude

Settings → Agents has a new "Claude Code mods" section with a switch for prismantis, a third-party mod that draws Claude Code replies as colored tables, code, diagrams and charts. Turning it on installs the version dev3 pins (a release reaches users only through a dev3 update) for every Claude account, including accounts that keep their own plugins; turning it off disables it and keeps its settings.
