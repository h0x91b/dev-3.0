Short: Accounts keep the project's Claude folder

Picking a Claude account for a task in a project with its own Claude folder now keeps that folder (its rules, skills, memory and status line) when the folder is already signed in to that account, instead of switching to the account's separate folder, and resuming such a task reopens the conversation in the folder it was written in. The launch account picker says on each account whether it runs in the project's folder or its own.
