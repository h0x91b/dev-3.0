Short: No tmux restart prompt after updates

An app update no longer asks to restart every task terminal: a tmux server whose bundle was replaced at the same path keeps its Documents, Desktop and Full Disk Access, so it is no longer flagged. When a restart is offered (a deleted copy, another copy, or a tmux this app cannot drive), the confirm now says how many task terminals close, names every agent that would be cut off mid-turn, and makes "Restart later" the default.
