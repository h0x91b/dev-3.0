Short: One row per login in the account picker

The launch account picker no longer lists the same Claude login twice in a project with its own Claude folder: a managed account, or `~/.claude`, signed in to the project's folder folds into the Project login row, which shows that account's usage and stays checked for a task that saved it. In a project whose settings switch Claude to Bedrock, Vertex AI, Foundry or env credentials, both rows stay and the project row says which backend it runs on.
