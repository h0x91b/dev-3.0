Project and space boards now render through a board host built on a Cordis plugin runtime: the search and filter row belongs to the host and is shared by every board view, the board's view choice and layouts are saved per board in a new `board-views.json` file, and the existing Kanban is mounted as the first board view. The board looks and behaves exactly as before; this is the groundwork for Table, Tree and Attention views and for board-view extensions.
