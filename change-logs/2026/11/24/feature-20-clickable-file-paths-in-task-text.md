Short: Clickable file paths in task text

File paths in task descriptions, notes, overviews and agent messages now open the in-app file preview when the file exists, at the written line for `path:12`; the full path shows on hover. Task and PR chips can also be selected and copied with the surrounding text. Windows paths (`C:\Users\me\x.md`, `src\app.ts`) are detected too, in task text and in terminal output. A path to a file in another project is written as `path:<project>/<path>`: dev3 converts one automatically when an agent writes a task for another board, every surface links it, and agents read it with its absolute path.
