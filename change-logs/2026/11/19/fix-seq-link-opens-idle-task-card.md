Short: Task links open idle tasks as their card

Clicking a `<seq:N>` link, the Open button of its hover preview, a `dev3://task/…` link or `dev3 task open` for a task that is not running (To Do, completed or cancelled) now opens that task's card on its board — with Run for a To Do task — instead of an empty task screen with no terminal. A hibernated task still opens on its wake screen.

Suggested by @banuni (h0x91b/dev-3.0#2347)
