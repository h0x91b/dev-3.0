Short: Antigravity CLI agent support

dev3 now runs the Antigravity CLI (`agy`) as a first-class agent: model presets in the Claude scheme (Auto, Bypass, Default, Plan, Accept Edits by model and effort), session resume by conversation id, automatic status hooks and the dev3 protocol written into the task worktree's `.agents/` folder (so they also work when a launcher overrides HOME), a trusted workspace so the trust dialog stays away, pre-approved dev3 metadata commands, permission waits read from agy's statusLine, and per-account quota (5-hour, weekly, other models) in the usage panel. A wrapper command can declare the `agy` family in Settings and gets the same handling. The launch pickers now list installed agents above the ones that are not.
