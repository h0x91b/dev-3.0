Short: Linux tmux spawn error names the real cause

When tmux cannot start on Linux, the error no longer sends you to macOS Full Disk Access. If the tmux binary is gone, for example an uninstalled Homebrew keg, it says so and tells you to reinstall it and reload dev3. If the file exists but cannot run, it says that instead.
