Short: Account name in the Claude statusline

A new opt-in setting, Settings → Agents → "Show account in statusline", starts dev3's Claude statusline segment with the account the session runs on (for example `work · 7d 30% ↻3d3h`), using the account's label or, when it has none, its email. Useful with "Auto (balanced)", which picks the account per launch; it is off by default and needs rate-limit tracking.
