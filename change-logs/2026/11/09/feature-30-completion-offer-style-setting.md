Short: Choose how completion asks appear

Settings → Tasks & Board → "How completion offers ask" picks how a merged branch or an agent's request to complete asks you: Dialog (the default) waits for an answer, while "On the task" shows a one-line bar at the bottom-right of the agent's pane, next to its prompt, and blocks nothing. Both check the branch for unsaved work before Complete, now for agent requests too, and a marker on the task's card and sidebar row shows which tasks are waiting.
