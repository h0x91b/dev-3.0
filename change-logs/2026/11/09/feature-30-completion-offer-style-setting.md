Short: Choose how completion offers ask

Merge and agent completion offers ask in a dialog again by default, so a finished task frees its agent, worktree and memory sooner; Settings → Tasks & Board → "How completion offers ask" switches to "On the task", which now shows a one-line bar at the bottom-right of the terminal, next to the agent's latest output, instead of a card at the top. Both styles run the unsaved-work check before Complete.
