Short: Clickable task and PR references

Agents now name tasks as `<seq:115>` (`<seq:proj/115>` across projects) and PRs as `<pr:115>`, and dev3 turns those tokens into links in the terminal, task descriptions, notes, overviews, the agent-traffic view and transcripts: a task opens in the app, a PR opens on GitHub. Hovering one previews it: a task shows its status, overview, latest notes, images and artifacts, a PR shows the same status popover as the card badge.
